# 수동 데이터 (공개 API 없는 지표)

## 매물량(`flow-listing`)은 왜 수동인가

매물량은 **신고 의무가 없는 지표**다. 거래·공급은 법정 신고 대상이라 정부가 집계하지만,
"팔려고 내놓은 물건"은 민간 플랫폼 등록 건수일 뿐이라 공공 통계로 존재하지 않는다.

전수 확인(2026-07-25):

| 소스 | 확인 방법 | 결과 |
|------|-----------|------|
| KOSIS | '매물' 등 4개 키워드 검색 | 없음 |
| KB 데이터허브 | 메뉴코드 01~08 probe | 심리·거래활발 6종만 |
| 부동산원 R-ONE | 738개 표 검색 | 0건 |
| 공공데이터포털 | 검색 | 실거래가(거래)만 |

민간(아실·네이버 부동산)은 `robots.txt`에 `User-agent: * / Disallow: /`로 봇 접근을
명시 거부하므로 자동 수집하지 않는다. → **수동 CSV가 유일한 경로.**

### 현재 반영된 파일

`asil_offer_counts_2021-01_2026-06.csv` (아실 집계, 전국+시도17, 66개월) — 검증 완료:
결측·월 끊김 0, 전국 = 시도 17개 합계 정확히 일치.

파일명은 `mapping.mjs`의 `manualFile`로 지정한다(원본 파일명을 그대로 쓰기 위함 —
복사본을 만들면 원본 갱신 시 어긋난다). 지정하지 않으면 `<지표id>.csv`를 찾는다.

### 새로 채울 때

`flow-listing.csv.example`을 참고해 `flow-listing.csv`로 저장하면 반영된다.
전 지역·전 기간을 채울 필요는 없다 — 매물량은 절대수치보다 증감 방향이 중요하므로
**전국·서울만, 최근 12~24개월만** 넣어도 해석에 쓸 수 있다.


공개 API가 없어 자동 수집이 불가한 지표는 여기에 CSV로 넣으면 `npm run refresh`가 스냅샷에 병합한다.

## 대상 지표 (파일명 = 지표 id)

| 파일 | 지표 | 출처 |
|------|------|------|
| `flow-buyer.csv` | 매수우위·매매수급지수 | KB부동산 주간시계열(엑셀) |
| `flow-sentiment.csv` | 부동산시장 소비심리지수 | 국토연구원 보도자료 |
| `flow-listing.csv` | 매물량 | 아실 등 민간 집계 |
| `pipe-movein.csv` | 입주물량 | 부동산원 보도자료 / 아실 (R-ONE OpenAPI 미제공) |

## 형식 (롱 포맷)

```csv
date,region,value
2024-01,전국,88.3
2024-01,서울,91.0
```

- `date`: `YYYY-MM` (필수)
- `region`: 시도명 또는 `전국` (생략 시 전국)
- `value`: 숫자 (필수)
- 헤더 필수. 순서는 무관, 이름으로 매칭.

`_template.csv`를 복사해 위 파일명으로 저장하면 된다. 파일이 없으면 해당 지표는 목업으로 폴백된다.
